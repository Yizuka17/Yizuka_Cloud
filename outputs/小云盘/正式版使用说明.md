# Yizuka Cloud Windows 云文件客户端

安装包：[YizukaCloudSetup.exe](https://github.com/Yizuka17/Yizuka_Cloud/releases/tag/v1.0.8)，版本 1.0.8。它在 Windows 10/11 文件资源管理器中创建“Yizuka Cloud”云文件夹。文件列表保留在本机，文件内容在打开时按需下载；网页与客户端使用同一个云盘账号。

双击安装包，选择一个本机 NTFS/ReFS 文件夹作为云文件夹和缓存位置。默认是当前用户目录下的 `Yizuka Cloud Files`。不能选择 `Y:\files`、`Z:\`、目录联接点、符号链接或它们的子目录。输入账号和密码后，安装程序会验证公网连接、安装组件并等待客户端启动。首次安装需要联网。此包使用自签名代码签名证书，安装程序会申请一次 Windows 管理员授权，自动将内置的 10 年签名证书加入本机“受信任人”证书库，不需要手动导入；它不是公共 CA 签名。

如自动导入证书失败，Release 附有公开证书 `Yizuka.CloudFiles.cer`。可在管理员 PowerShell 中使用 `Import-Certificate -FilePath .\Yizuka.CloudFiles.cer -CertStoreLocation Cert:\LocalMachine\TrustedPeople` 后重试安装。不要导入“受信任的根证书颁发机构”。证书指纹为 `D46F1443DB5A0DFA8688FA07FF630A6F97AC6F97`，有效期至 2036-10-03；Release 不包含私钥。

安装后，在资源管理器左侧打开“Yizuka Cloud”。托盘云朵图标双击打开当前可用的网页端；右键菜单可打开云文件夹或立即同步。在资源管理器里查看云文件夹时，按 F5 也会请求即时同步。正常情况下客户端每小时检查一次云端变化；网络故障后每分钟重试。它自动优先选择本机服务、局域网 HTTPS，然后是 Cloudflare 公网地址。外网大文件上传使用分块上传。

断网时，文件夹入口会保留。已缓存的文件可能仍能读取；未缓存文件需要网络恢复才能打开。Windows 可以回收已同步文件的本地内容，但本版尚不提供精确缓存容量上限。云文件夹内的删除会同步到服务器；本机编辑和服务器编辑同一文件时，客户端会保留两端内容并暂停自动覆盖，需要人工处理冲突。客户端完全退出期间发生的本地删除不会自动推断为云端删除。

本机旧版 `Z:` rclone 挂载和测试版入口已停用；新的云文件夹是正式客户端。服务器数据存放在实体 `Y:\files`，安装客户端不需要改动这块分区。其他电脑只需复制安装包并在那台电脑上安装、授权；不要复制本机的 DPAPI 密码文件。

验证安装：可查看 `%LOCALAPPDATA%\YizukaCloud\cfapi-release-service.log`。如果安装程序提示启动失败，检查该日志和网络连接后重试安装。卸载可在 Windows“应用和功能”中卸载 Yizuka Cloud；云端 `Y:\files` 数据不会因此删除。卸载前先确认本地修改已同步，并自行处理需要保留的本地缓存文件。

安装包的 SHA-256 记录在 [YizukaCloudSetup.sha256.txt](YizukaCloudSetup.sha256.txt)。
